## 🌸 About

**Bloom Flowers** is a Flutter-based flower-commerce application with separate **Customer** and **Admin** experiences.

Customers can browse products, manage favourites and cart, place gift orders, create gift messages, and track their orders. Admins can manage products, inventory, categories, and orders.

## ✨ Highlights

* 🔐 Firebase Authentication
* 🛍️ Product browsing, search, favourites & cart
* 🎁 Gift orders with recipient and delivery details
* 💌 In-app gift message creation and editing
* 📱 WhatsApp customer support
* 📦 Order tracking and status management
* 🌿 Admin dashboard and product management
* ☁️ Cloudinary image hosting
* 🔄 Firestore transactions for inventory operations
* 🎨 Custom Material 3 UI and animations

## 🛠️ Tech Stack

**Flutter · Dart · Firebase Auth · Cloud Firestore · Cloudinary · Material 3 · SharedPreferences**
